## Options

| Option | What happens if chosen | Risks and how to undo |
|---|---|---|
| Variant A, centered | Ship the single-column page with the blue button. | Less room for proof. Undo by switching the file back. |
| Variant B, split | Ship the two-column page with the testimonial. | Cramped on phones. Undo by switching the file back. |
| Keep the current page | Change nothing. | Sign-ups stay flat. Undo: nothing to undo. |

## Recommendation

Variant A, centered. The form is above the fold on every screen size. Variant B is right if the testimonial matters more than mobile speed.
