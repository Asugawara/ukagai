## 見つけた不具合

| # | 重さ | 内容 |
|---|---|---|
| B1 | **重要** | `install --data-dir <dir>` は引数を読むだけで、登録する hook に渡さない(`src/settings/target.ts` は `dataDir` を持つが、`src/settings/hooks-spec.ts` は `--data-dir` を args に出さない)。`serve --data-dir X` で起動すると hook は `~/.ukagai/token` を読めず認証に失敗し、**黙ってフェイルオープン**する。再現: `serve --port 4818 --data-dir /tmp/ukagai-v1` → install → probe で AskUserQuestion → GUI に出ず通常 UI。ユーザーには原因が見えない(doctor が `--data-dir` を見るかは未確認) |
| B2 | **重要** | Stop の `escaped_question` の検出が粗く、「どちら」を含む復唱・説明の文で誤検出する(3/3 件)。(a') の分母が膨らみ、答え 3 件 + フォールバック 1 件で rate が 0.43 になる。計画 3 節の「粗い検出」の仕様どおりだが、dogfood の指標が使えない水準 |
