# public/

`ukagai serve` が配信する GUI。ビルド無しの静的ファイル。`GET /` が `index.html` を返し(cookie を発行)、他は `/public/*`。

- `index.html` — 骨組み(header、左「背景」、右「判断」、保留一覧のドロワー、トースト)
- `app.js` — ES module。API 呼び出し、SSE、描画。ユーザー由来の文字列は `textContent`
- 1 画面(ページはスクロールしない。収まらないときだけ列内でスクロール)。header は無い(main が画面全体)。保留 2 件以上のときだけ右上に小さい「保留 N」が出て、押すと保留一覧のドロワーが開く(既定は閉)。metrics とセッション一覧は無い。右列の title の直下に、ブランチ(`context.branch` だけ描画)・作業ディレクトリのフルパス・可逆性・scope・経過時間を出す
- **GUI は説明ファイルで判断画面を組む。生の AskUserQuestion は説明なし(`attached_via: none`)のときだけ**(仕様は説明ファイル v2。`title` / 「推奨」節 / 「選択肢」表)
  - 右「判断」: `title` → 「推奨」節(accent 枠)→ 選択肢カード(表の行ごと。ラベルは `(Recommended)` 等を外し、推奨にバッジ。「選ぶと起きること」を本文、「リスクと戻し方」を薄く)→ 自由記述。元の質問文と `description` は、表と対応が取れた選択肢では出さない(表に行が無い option だけ生のラベル + description で補う。2 問目以降は生のまま)。回答は表の見た目でなく元の `option.label` で返す
  - 左「背景」: 本文から「選択肢」「推奨」の節を除いた残り(marked の出力 DOM を h1〜h3 で切って振り分ける)。説明なしのときは「エージェントは説明を書きませんでした」の 1 行だけ
  - 旧形式の表(利点・欠点・コスト)でも落ちない。2 列目以降を順に本文として出す
  - **補助文脈(`context`)は描画しない**(`branch` を除く)
- 回答すると 2 秒のトーストを出して次の保留(最も古いもの)へ自動で移る。無ければ空状態
- キーだけで答えられる(vim 風。マウス不要)。画面の操作対象には割り当てキーを `<kbd>` チップで添える。質問: `j` / `k`(`↓` / `↑`)で移動(単一選択は移動 = 選択、端で止まる)、`gg` / `G` で先頭 / 末尾、複数選択は `Space` で切替、`Enter` で送信、`i` で自由記述の欄へ(欄内 `Esc` でカードに戻る、`Enter` で送信)。計画: `j` / `k`(`←→↑↓` も)+ `Enter`、`y` 承認 / `a` 承認して auto / `n` 却下(理由欄。`Esc` で取りやめ)。共通: `h` / `l`(`Tab` / `Shift+Tab`)で前 / 次の保留、`b` で保留ドロワー(`j` `k` `Enter` `Esc`)。ボタンにフォーカスがあっても移動・文字キーは効く。fallback ボタンは無い(API の `{fallback:true}` は残るが GUI は送らない)
- 質問カードは各質問の選択肢の下に「自由記述」(単一選択はラジオ、複数選択はチェックボックス)とテキスト入力を出す。選ばれていれば answers の値はその文字列(複数選択は選んだラベルの後ろに足す)。空文字では送れない
- `GET /` は `app.js` / `app.css` の URL に更新時刻の版(`?v=<mtimeMs の 36 進>`)を付け(`/public/*` は query を無視)、`app.js` は右列のヒント行の末尾(空状態は右下)に `build <v>` を薄く出す。古い版を見ていないかはこれで分かる
- `app.css` — システムフォント、2 列(背景 3fr / 判断 2fr、900px 未満は 1 列で判断が先)、ダークモードは `prefers-color-scheme`
- `vendor/` — `mermaid.min.js` と `marked.umd.js`(コミット対象。CDN は使わない)

vendor の更新: `npm ci` の後に `npm run vendor`(`node_modules` から `public/vendor/` へ cp)。
