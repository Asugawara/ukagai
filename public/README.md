# public/

`ukagai serve` が配信する GUI。ビルド無しの静的ファイル。`GET /` が `index.html` を返し(cookie を発行)、他は `/public/*`。

- `index.html` — 骨組み(header、左「背景」、右「判断」、保留一覧のドロワー、トースト)
- `app.js` — ES module。API 呼び出し、SSE、描画。ユーザー由来の文字列は `textContent`
- 1 画面(ページはスクロールしない。収まらないときだけ列内でスクロール)。header は無い(main が画面全体)。保留 2 件以上のときだけ小さい「保留 N ← →」が出て、押すと保留一覧のドロワーが開く(既定は閉)。位置は 1100px 以上なら画面の右上(固定)、1100px 未満なら右列の見出し行の右端(インライン)。metrics とセッション一覧は無い。右列の title の直下に、ブランチ(`context.branch` だけ描画)・作業ディレクトリのフルパス・可逆性・scope・経過時間を出す
- **GUI は説明ファイルで判断画面を組む。生の AskUserQuestion は説明なし(`attached_via: none`)のときだけ**(仕様は説明ファイル v2。`title` / 「推奨」節 / 「選択肢」表)
  - 右「判断」: `title` → 「推奨」節(accent 枠)→ 選択肢カード(表の行ごと。ラベルは `(Recommended)` 等を外し、推奨にバッジ。「選ぶと起きること」を本文、「リスクと戻し方」を薄く)→ 自由記述。元の質問文と `description` は、表と対応が取れた選択肢では出さない(表に行が無い option だけ生のラベル + description で補う。2 問目以降は生のまま)。回答は表の見た目でなく元の `option.label` で返す
  - 左「背景」: 本文から「選択肢」「推奨」の節を除いた残り(marked の出力 DOM を h1〜h3 で切って振り分ける)。説明なしのときは「エージェントは説明を書きませんでした」の 1 行だけ
  - 旧形式の表(利点・欠点・コスト)でも落ちない。2 列目以降を順に本文として出す
  - **補助文脈(`context`)は描画しない**(`branch` を除く)
- **blocker(人の作業待ち。`explanation.type === "blocker"`、front matter の `type` でも同じ)**: 右列の title の上に橙の帯「人の作業待ち」(`--blocker`)、title の直下に「人にしてほしいこと」の節(橙枠。左列ではなくここ。コードブロックの右上に `コピー`、キー `c` で最初のブロックをコピー。`navigator.clipboard`)、その下に 3 択のカード。「推奨」節が無ければボックスは出さない。左列は「なぜ止まったか」と残りの節。保留ドロワーの行に橙の「作業」バッジ。blocker が保留にあるとき `document.title` は `(N) ukagai · 作業待ち`。初期カーソルは `recommended`(対応した。続けて)で、`Enter` だけで再開できる
- **長い説明は折りたたむ**(hook の長さ上限 = spec 3.6 を守っていれば発動しない)。推奨ボックスは最大 6 行(`.rec-body` の `max-height`、下端を薄くフェード)、「選ぶと起きること」「リスクと戻し方」は 1 カード各 3 行(`-webkit-line-clamp`)。溢れる要素にだけ右下に `全文 .` のチップを出し、`.` キーかクリックで全体を展開 / 折りたたみ(状態は判断ごと)。展開中は右列がスクロールする
- 回答すると次の保留(最も古いもの)へ自動で移る。無ければ空状態
- **トースト**: 右列の送信ボタン(`.actions`)の上に縦に積む(最大 3 枚。判断が無いときだけ右下)。回答 / コピー / 「届きました」(自分の回答の確定、背景の判断の answered)は 2 秒。表示中でない判断が失われたとき(`answer_lost` / `hook_disconnected` / `fallback`、回答済みの `cancelled`)は赤で 4 秒「<title> は届きませんでした(理由)」。回答していない判断が `cancelled` になったときは赤 4 秒「<title> は取り消されました」
- **広い図**: 図の自然幅が列幅の 1.5 倍を超えると「全幅で見る f」チップが出る。`f`(またはチップ)で判断列を隠して図を全幅で出す(足りなければ横スクロール)。全幅中は `Enter` は無効(送信しない)、`Esc` / `f` / `Tab` で戻る。判断を切り替えると解除
- **右列の「影響範囲と可逆性」**(計画): 計画本文の同名の節をボタンの上に出す。8 行で畳み、`.` か「全文 .」チップで展開。節が無ければ出さない。コードブロックは 9 行を超えると `<details>` で畳む
- **接続**: 401 のときは `GET /` で cookie を取り直して 1 回だけ再試行(それでも 401 なら「ページを再読み込みしてください」)。SSE が切れたら 2 → 4 → 5 秒(上限)で再接続し、再接続したら保留を取り直して同期する(消えた判断は一覧から除く)
- **画像**: 説明内の `<img>` は `data:` だけ残す(外部・相対・同一オリジンの `src` は除去)。インラインコード(`code`)は折り返さない(`white-space: nowrap`)
- 矢印キーだけで答えられる(マウス不要)。画面の操作対象には割り当てキーを `<kbd>` チップで添える。質問: `↑` / `↓` で移動(単一選択は移動 = 選択、端で止まる)、`Home` / `End` で先頭 / 末尾、複数選択は `Space` で切替、`Enter` で送信(自由記述カード上で欄が空なら欄へ)。自由記述の欄内は `Esc` でカードに戻る、`↑` / `↓` でカードに戻って移動、`←` / `→` は欄内のカーソル移動。計画: `↑` / `↓` でボタン移動 + `Enter`(`y` / `a` / `n` のチップも押せる。`n` で理由欄、`Esc` で取りやめ)。共通: `←` / `→` / `h` / `l`(`Tab` / `Shift+Tab`)で前 / 次の保留、`b` で保留ドロワー、`.` で長い節の展開 / 折りたたみ、`c` で最初のコードブロックをコピー(blocker)、`f` で広い図の全幅表示。保留ドロワーは `↑` / `↓`(`j` / `k`)で行移動、`Enter` で切替、`Esc` / `b` / `←` で閉じる。質問の文字キーは `j` `k` `gg` `G` `i`、計画は `j` `k` `y` `a` `n`。ボタンにフォーカスがあっても移動キーは効く。fallback ボタンは無い(API の `{fallback:true}` は残るが GUI は送らない)
- 質問カードは各質問の選択肢の下に「自由記述」(単一選択はラジオ、複数選択はチェックボックス)とテキスト入力を出す。選ばれていれば answers の値はその文字列(複数選択は選んだラベルの後ろに足す)。空文字では送れない
- `GET /` は `app.js` / `app.css` の URL に更新時刻の版(`?v=<mtimeMs の 36 進>`)を付け(`/public/*` は query を無視)、`app.js` は右列のヒント行の末尾(空状態は右下)に `build <v>` を薄く出す。古い版を見ていないかはこれで分かる
- `app.css` — システムフォント、2 列(背景 3fr / 判断 2fr)。900px 未満は 1 列(判断が先)。保留ボタンの切替点は別で 1100px(以上は右上固定、未満は見出し行)、ダークモードは `prefers-color-scheme`
- `vendor/` — `mermaid.min.js` と `marked.umd.js`(コミット対象。CDN は使わない)

vendor の更新: `npm ci` の後に `npm run vendor`(`node_modules` から `public/vendor/` へ cp)。
